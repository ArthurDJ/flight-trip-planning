# 决策框架

## 1. 真实总价

比的是这趟行程实际要花多少钱，不是标题票价。

| 组成 | 何时计入 | 说明 |
|---|---|---|
| 含税票价 | 始终 | 航司官网、同一行程、同一票种 |
| 托运行李 | 任一方向要托运 | 按方向计；以添加时价格为准；网上提前付通常比机场便宜 |
| 登机箱 | 票价不含（基础票、低成本航司） | |
| 选座 | 需要坐在一起或指定座位 | |
| 地面交通 | 不同机场离真实目的地远近不同 | 停车、打车、过路费、接机人的时间 |
| 时间成本 | 用户给出时间价值，或选项相差一晚或一天 | 只有用户同意具体数字时才计入 |

同时列出总价和各部分；某部分没计入，在同一行注明。

## 2. 偏好档位

用档位代替严格的优先级顺序（严格顺序会得出"多付 $359 换 10 分钟车程"这种结论）。每个档位是一组**兑换率**：为某项改善愿意多付多少钱。

| 档位 | 价格 | 灵活性 | 转机安全 | 时刻舒适 | 机场便利 |
|---|---|---|---|---|---|
| **省钱** | 最重要 | 计划确定时可接受基础票 | 接受最短合法中转 | 可接受红眼和早班 | 低 |
| **均衡**（默认） | 高 | 可改签票 | 不低于舒适余量 | 避开红眼航班 | 中 |
| **舒适** | 中 | 可改签 | 宽裕余量 | 白天、少转机 | 高 |
| **计划不确定** | 中 | **退回原支付方式，或旅客一定用得上的 credit** | 宽裕余量 | 中 | 低 |
| **家庭 / 团体** | 中 | 可改签 | 宽裕余量，不做紧张的自助转机 | 避开太早出发 | 高 |

**均衡**档的默认兑换率（用户可以改任何一项）：
- 直飞 vs 转一次：每人最多值 $100
- 白天到达 vs 深夜到达：最多值 $50
- 首选机场 vs 可接受名单里的其他机场：最多值 $40
- 后续航班是当天最后一班时，转机余量每多 30 分钟：最多值 $30

每条推荐都用金额写取舍："方案二多付 $27，13:17 到达，而不是 19:38。"

## 3. 灵活性：可退 vs credit vs 基础票

票种分类（名称因航司而异，需逐家核实票价家族）：

| 类别 | 改签 | 取消 |
|---|---|---|
| **A：可退** | 可以，补差价 | 退回原支付方式（有时扣手续费） |
| **B：可改** | 可以，补差价 | 航司 credit（有效期和谁能用因航司而异） |
| **C：基础** | 不可改或高额手续费 | 作废或部分 credit |

### 盈亏平衡判断（A vs B）

输入：`R` = A 的价格，`C` = B 的价格，`P` = 行程取消的概率，`f` = B 的 credit 中预计用不掉的比例（过期，或这家航司不适合旅客以后的出行）。

```
行程成行 (1 − P)：A 花 R，B 花 C
行程取消 (P)：    A 全额退款 → 花 0；B 剩下价值 (1 − f)·C 的 credit → 损失 f·C

E[A 的成本] = (1 − P)·R
E[B 的成本] = (1 − P)·C + P·f·C

当 (1 − P)·(R − C) < P·f·C 时选 A
   ⇔ P > P* = (R − C) / ((R − C) + f·C)
```

溢价 `R − C` 只有成行时才真正花掉：取消 A 时溢价也一起退回。（v2 用 `P·f·C` 和整个溢价比，高估了阈值。）

例：R − C = $156，C = $501。
- credit 会全部浪费（f = 1）：P* = 156 / (156 + 501) = 156 / 657 ≈ 23.7%。取消概率超过大约 1/4，A 更划算。
- credit 能用掉一半（f = 0.5）：P* = 156 / (156 + 250.5) ≈ 38.4%。
- credit 几乎一定用得上（f ≈ 0）：A 几乎不划算。

变体：
- **A 取消要扣手续费 `x`**（退款扣费）：E[A 的成本] = (1 − P)·R + P·x，所以 P* = (R − C) / ((R − C) + f·C − x)。例中 x = $100 时：156 / 557 ≈ 28.0%。如果 x ≥ f·C，A 永远不划算。
- **更可能发生的是改期而不是取消**：改期后行程照样成行，属于"成行"分支。如果两种票都只补差价就能改，改期在 A 和 B 上成本相同，溢价对改期没有任何价值；`P` 只用真正取消的概率。如果 B 改期收手续费 `g` 而 A 不收，在 E[B 的成本] 上加 `P_change·g`：当 (1 − P)·(R − C) < P·f·C + P_change·g 时选 A。

在推荐旁边写出输入（R、C、P、f，用到时加 x 或 g）和结果，方便用户改一个输入重新算。能用计算器或代码时就用。

决定 `f`（credit 用不掉的比例）的问题：
- 未来 12 个月里，这家航司有没有从旅客居住地出发的航线？
- credit 有效期多长，能不能给别人订票？
- 旅客会不会**改期**而不是取消？B 类票改期通常完全不用 credit（只补差价）。

### 容易漏的细节
- 退款通常要求**起飞前取消**；不登机也不取消可能失去退款资格。
- "免费改签"指免手续费，不是免差价；差价按改签当天票价计算。
- 高端经济、商务、头等**不自动可退**，很多航司卖不可退的版本。
- 部分使用：去程飞了、回程没用，能退多少看票价规则。
- 很多国家在订票后有短暂的免费取消窗口（例如美国在航司直订的 24 小时规则），可作为最后确认。

## 4. 票价动态

- "只剩 N 座"通常指**价位档**，不是整架飞机；卖完后价格跳到下一档。
- 节假日票价一般越临近越贵，但涨多少、何时涨无法预知，不承诺方向。
- 可退或可改的票相当于对冲：现在订锁价；降价时取消（A）或改签（B，前提是航司退或补差额）再重订。**先取消并确认退款，再重新下单**，避免同一个名字两份订单。
- 该买还是该等的预测和价格追踪交给专门工具，并说明不保证准确。

## 5. 付款卡

- 返现或积分只有成行才算数；退款时通常会被扣回。
- 信用卡附带的行程取消险一般只赔**不可退**票，且理赔原因有限（疾病、死亡、航司破产），不含"计划变了"。
- 部分卡的航班延误险、行李险，对冬季转机行程可能比返现更有价值。
- 不要为了卡的旅行平台多拿积分，而违反"在航司官网订票"的规则。
