## 全球通用检查（任何跨境行程）

- **护照有效期**：很多国家要求超出停留期（常见 6 个月）。
- **入境许可**：按旅客国籍确认签证、eTA / ESTA 类电子许可或免签；签证类别要与出行目的相符。
- **过境**：部分国家即使不出机场也要过境签证；隔夜换机场或换航站楼可能需要入境。经美国机场转机就要在那里过 CBP（见"带日期的事实"），所以执行时按旅客国籍核实美国入境证件。
- **回居住国**：重新入境居住国所需文件（居留卡、许可、再入境签证）在回程日期必须有效。
- **申请审理中**：问清出境是否影响在审的移民或签证申请、或靠申请维持的身份。如果审批结果可能迫使取消行程，写成取消触发条件，并把档位调到"计划不确定"。
- **在哪里过海关**：在第一个入境点，除非出发机场有预清关；行李可能要在入境点提取后重新交运。
- **乘客权益制度**按国家不同、按航班适用（如美国 DOT、加拿大 APPR、欧盟 EU261）。
- **币种**：票价和行李费按始发地币种计价，回程可能不同。
- **时区**：各地夏令时切换日期不一致，有些地区已经不再切换（见"带日期的事实"）。

## 北美模块

### 美国境内
| 主题 | 检查 |
|---|---|
| 证件 | 成人需 REAL ID 合规证件或护照；非美籍旅客带护照 |
| 海关 | 无；转机在安检区内完成 |
| 退款权益 | 24 小时规则（见"带日期的事实"）；航司取消或重大变更、旅客不接受替代方案时可退款，基础票也一样。这是"必须退现金"场景下拿回现金的一条路 |
| 票种 | 基础经济舱常不可改，可能不含登机箱或选座；Main 一般可改、取消退 credit；可退票价单独销售 |
| 行李 | 通常另付；网上提前付往往更便宜 |
| 时区 | 本土 4 个时区加阿拉斯加、夏威夷；亚利桑那大部分不实行夏令时 |
| 转机 | 国内转国内一般 45–90 分钟（参考，不是规定）；冬季北部枢纽易延误 |

### 加拿大境内
| 主题 | 检查 |
|---|---|
| 证件 | 成人需政府签发证件；外籍旅客带护照 |
| 海关 | 无 |
| 退款权益 | APPR：航司取消且无法在规定时间内改签时，可退回原支付方式；赔偿按原因和航司规模区分 |
| 票种 | 部分航司**经济舱没有可退现金的票种**，只有高端票价家族退回原支付方式 |
| 行李 | 低价票可能不含登机箱；与低成本航司比要算总价 |
| 时区 | 6 个时区，含纽芬兰半小时时区；萨省大部分不实行夏令时；BC 省全年 UTC-7（见"带日期的事实"） |
| 转机 | 小机场冬季多雾和降雪；每天班次少，误机可能要等到次日 |

### 美国 ⇄ 加拿大
| 主题 | 检查 |
|---|---|
| 证件 | 护照（或按国籍可用的替代证件）；按国籍确认美国签证 / ESTA 和加拿大 TRV / eTA；签证类别与目的相符 |
| 回加拿大 | 非公民居民：PR 卡 / PRTD，或工签 / 学签加有效 TRV（如需要）；航司登机前会查 |
| 移民申请在审 | 出行对在审申请或维持身份的影响；登陆与出行的时间衔接；写出取消触发条件 |
| 进入美国 | 从有预清关的机场出发（见"带日期的事实"）：出发前过美国海关和移民，到达时不过 CBP 和 TSA。在加拿大有预清关的枢纽转飞美国（例如萨斯卡通 → 多伦多 → 芝加哥）：预清关在枢纽完成，是一个转机步骤。从其他加拿大机场出发：在第一个美国机场过 CBP，然后重新安检 |
| 进入加拿大 | 在第一个加拿大机场过 CBSA；国际转国内时部分机场要提取行李重新交运。从北美以外经美国枢纽飞加拿大：旅客在该枢纽过 CBP（需要美国入境证件），除非适用 CBP 试点，否则要在那里提取并重新交运行李，再在加拿大过 CBSA |
| 退款权益 | 往返美国的航班适用 24 小时规则；进出及加拿大境内航班适用 APPR；第三方平台不一定执行 24 小时规则 |
| credit | 旅客要搬家时，确认航司是否有从新居住地出发的航线 |
| 时区 | 省、州规则不同步，BC 省已不再切换；按出行日期重新核实时差 |

## 其他地区（起步检查）
- **欧盟 / 英国**：EU261 / UK261 乘客权益；申根 90/180 天规则；首次进入申根时的 EES 登记会增加过关时间，在那里转机要多留余量；ETIAS 目前不需要（见"带日期的事实"）；生效地区的 UK ETA，执行时核实
- **亚太**：枢纽机场过境签证规则；长时间中转可能需要入境；低成本航司行李和选座费
- **拉丁美洲**：旅游卡、登机时查验离境机票；票价币种

行程需要时，按北美模块的表格格式补充完整模块。
