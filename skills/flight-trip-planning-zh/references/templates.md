# 模板

## 1. 问询

只问会改变决策的问题，括号里给默认值，用户回答"可以"即可。

**快速模式**：需要知道的内容。答案先从消息里找；只问消息里没有的（通常 0–2 个），并说明用了哪些默认值。
1. 谁坐、从哪到哪、哪几天？［1 位成人，经济舱］
2. 行程变动或取消的可能性大吗？［低 → 均衡档］
3. 去回程各带什么行李？［只带登机箱］
4. 有没有不能接受的机场或时段？［没有］
5. 预算上限？［无］

**标准模式增加**
6. 取消时能不能接受航司 credit，一年内会不会用掉？→ 决定退改类别
7. 谁订票、谁出行？旅客本人会看结果吗？→ 是否需要旅客精简版
8. 跨境时旅客国籍和证件；有无待定的签证或移民审批 → 取消触发条件
9. 可接受的备选机场，以及从各机场到目的地的交通
10. 选择档位，或用户自定兑换率

**详细模式增加**：各日期的时段限制、最长时长和转机次数、谁来审核、输出格式。

## 2. 需求文档（详细模式）

```
# <行程> 需求文档  vX.Y（日期，变更摘要）
背景：为什么灵活性 / 退款 / 证件重要

## 硬性筛选
H1 出发窗口（时区）
H2 返回窗口；最晚到达（时区）
H3 最多转机次数和最长门到门时长
H4 退改类别（A / B / C）以及何时可接受 B
H5 行李安排
H6 出票：同一张票（一个 PNR），在航司官网订
H7 转机可行性（海关、重新交运、稀缺航段）
H8 证件（写明是出票前还是出发前完成）

## 档位与兑换率
## 航司与机场范围（含排除理由）
## 时差规范
## 输出格式
## 执行边界：只查询；由本人订票付款
```

每条筛选都要能检查（有数字、有时区、有判定方法），条件之间不得矛盾。

## 3. 对比卡

### 精简卡（快速模式）

最多 3 个方案，每个一块：

```
1. <航司和航班> · <总价>（<票价> + <行李>）· <票种，几个字说明改签 / 取消>
   <日期 起飞 → 到达>，<直飞 | 在 X 转 1 次，转机时长>
   取舍：<一句话，用金额写>
```

两个机场同一时区时只写一个时间；否则写"当地时间（另一地时间）"。然后一句话推荐。用户不问就不列排除清单。

### 对比卡（标准和详细模式）

| # | 航班（运营方） | 去程：起飞 → 到达（两地时间） | 回程：起飞 → 到达（两地时间） | 转机 / 风险 | 类别 | 口径 | 票价 | 行李 | **总价** | 取舍 |
|---|---|---|---|---|---|---|---|---|---|---|

口径：单程还是往返，同一订单还是分开订。然后：一句话推荐；后两名为什么落选（用金额说明）；排除了什么、为什么（简短）。

### 多城市和开口程卡

| # | 第 1 段：起飞 → 到达 | 第 2 段：起飞 → 到达 | 第 3 段：起飞 → 到达 | 地面衔接（时间、费用） | 订单（同一张或分开） | 类别 | **总价** | 取舍 |
|---|---|---|---|---|---|---|---|---|

按需要增减航段列。开口程两点之间的地面交通计入真实总价。

## 4. 旅客精简版（标准及以上）

- 标题：用大白话写日期和路线
- 一行时差说明（如有）
- 前 3 个方案，每个：含行李的价格、去回程两地时间、转机时长、1–2 个标签（"最便宜""回程转机较紧"）
- 3–5 条注意事项：怎么取消、何时之前取消、行李、姓名与护照一致、要核对的证件
- 不放矩阵、排除清单和术语

## 5. 给其他 agent 的交接消息

内容自包含，不引用对方打不开的文件。
包括：需求要点、时差规范、带数字的推荐、价格矩阵摘要、转机风险、排除及原因、对其上一版的修正、待办。

## 6. 完整结果文件（详细模式）

章节固定，没有内容写"无"：
1. 结论（前 3 名及理由）
2. 候选总表（对比卡字段加官网链接和票种）
3. 价格矩阵（出发日 × 回程日，按机场分组），需要时加舱位对比
4. 逐条转机评估
5. 排除清单（违反的条件或理由）
6. 特殊日期结论（"有解"/"无解"及依据）
7. 查询记录（网站、组合、时间、跳过的登录、未核实项）

## 7. 出票清单（给本人）

1. 在自己的浏览器打开航司官网，选中完全相同的航班。如果 agent 没能在官网核实，现在核对价格、票种和行李
2. 选与决策一致的票价家族（选了可退就加上可退选项），确认总价
3. 乘客姓名与护照一字不差
4. 选定付款卡（退款原路退回）
5. 付款前截图退改条款
6. 托运行李一般可以之后在"管理行程"里添加

## 8. 出票后核对

以**确认页或确认邮件**为准（结账页不能证明已出票）：
- [ ] 有确认码
- [ ] 航班、日期、时刻与决策一致
- [ ] 总价与预期票种一致（可退票的价格能反证票种）
- [ ] 乘客全名与护照一致
- [ ] 改签取消条款原文符合预期
- [ ] 记下免费取消窗口的截止时间
- [ ] 出票记录写入结果文件
- [ ] 含付款信息的文件删除或私密保存
- [ ] 提醒：出发前添加行李；取消触发条件出现时**在起飞前**取消；可开启价格追踪，降价时取消重订
