# 核实与可行性

## 1. 官网核实

1. 搜索工具和聚合平台只用来**发现**行程。快速模式只核实推荐方案和第二名；标准和详细模式核实每个候选。没有浏览器时，见 `SKILL.md` → 缺少工具时。
2. 对每个候选行程，打开**运营或出票航司官网**，搜索同一航班同一日期，记录：
   - 票价家族 / 票种（如 Saver、Main、Refundable、Flex）
   - 含税总价、币种、不包含什么（行李、选座）
   - 改签和取消条款（简短引用航司原文）
   - 查询时间
3. 官网查不到、或官网价格不一致且无法解释的行程，剔除。
4. 标明价格类型：**起价**（选择前显示的该舱最低价）vs **选定总价**（去回程都选好后）。只有选定总价是最终价。
5. 结果整齐得可疑（多个日期价格完全相同）时，先在官网页面抽查一格再采用。
6. 遇到登录、验证码或身份验证页面，不输入任何信息；跳过或交给本人，并记入查询记录。

同一张票：一次下单、一个 PNR（订座记录编号），可含合作伙伴运营航段。同一航司分两次下单**不算**。聚合平台的"虚拟联程"和"Hacker Fares"组合通常是分开的票：前段延误误机没有保护，行李要重新托运。

**最短中转时间（MCT）**：一个机场的航司之间约定可以出售的最短中转时间（在当地商定，经 IATA 批准；单个航司可以另报例外）。航司出售的同一张票的联程满足 MCT，这就是"合法中转"的意思。合法只代表能卖，不代表从容：MCT 不为前段晚点、排队或换登机口留余量。同一张票因前段原因误机，由航司负责改签（以其运输条款为准）；分开出票时没有人检查 MCT，风险由旅客承担。

## 2. 倒推法

覆盖漏洞通常来自只搜了最显眼的出发时段。

1. 找出每个方向**最稀缺的航段**（例如每天只有一班飞小机场的航班）。
2. 倒推：哪些前段航班能留足余量接上这个稀缺航段？由此确定起点最晚出发时间。
3. 窗口内**每一天、每个时段**（早、中、晚）都要搜，并记录搜过哪些组合。
4. 写明错过稀缺航段的后果：晚几小时、改到次日、还是违反硬性条件。

## 3. 转机评估

列出每个转机点要完成的步骤并估算时间：

1. 下飞机（支线小飞机要在舱门口等登机口托运的登机箱）
2. 步行或乘机场轻轨
3. 入境 / 海关（如在此入境；从境外到达且未预清关时，美国机场一定是入境点，转机旅客也一样；见 `references/regions.md` → 带日期的事实）
4. 出境一侧的边检（如下一班从这里出境且有预清关，例如在加拿大枢纽飞美国前过美国预清关）
5. 提取并重新交运行李（如需要）
6. 重新安检（如需要）
7. 走到下一个登机口；登机通常在起飞前 15–20 分钟截止

风险等级（参考）：
低于 MCT 的联程无法在同一张票里订到；等于 MCT 时，风险等级取决于上面的步骤。

- **低**：所需步骤正常耗时之外还有 30 分钟以上余量
- **中低**：余量 15–30 分钟，或步骤简单但时间偏短
- **中**：需过海关或重新交运且余量不足 30 分钟，或节假日 / 冬季高峰
- **高**：余量低于正常耗时，或依赖前段准点

去程和回程分别评估：错过的后果不同，权重不同。用新签证首次入境可能被二次询问，要留余量。

给旅客的建议：尽量只带登机箱、坐靠前、证件随手可取、用航司 App 看登机口变化、前段延误时马上联系航司。

## 4. 时差

1. 按**出行日期**核实各地 UTC 偏移（夏令时切换日、固定或调整过时区的地区，例如 BC 省，见 `references/regions.md` → 带日期的事实）。
2. 跨时区时间一律写成"当地时间（另一地时间）"。
3. 硬性条件写明按哪个时区（"按目的地时间 20:00 前到达"）。
4. 行程时长以航司给出的实际经过时间为准，不用钟面时间相减。
5. 接机时间按接机人所在地的当地时间给出。

## 5. 审核清单（审核另一个 agent 的结果）

- [ ] 按最新版需求执行（没有引用旧版的偏好）
- [ ] 覆盖完整：所有可接受机场、窗口内每一天、每个时段
- [ ] 每个价格都在官网核实，口径写清（含税、行李、单程 / 往返、可退与否）
- [ ] 退改类别正确，没有把高端舱默认当成可退
- [ ] 差价、总价等算术正确
- [ ] 盈亏平衡用 P* = (R − C) / ((R − C) + f·C)，并写出输入（不是 P·f·C > R − C）
- [ ] 时差按出行日期核实并标两地时间
- [ ] 转机评估覆盖海关、重新交运、稀缺航段风险
- [ ] 排除清单、特殊日期结论、查询记录齐全
- [ ] 没有无依据的保证（"改期不用补差价""肯定赶得上"）
- [ ] 可疑的整齐数据已抽查
- [ ] 没有编造的价格、航班号或时刻；没在航司官网看到的内容都标"未核实"

逐条回复：成立 / 部分成立 / 不成立，附依据和处理方式。合并两份结果时，结构取更完整的一方，数据取覆盖更全且核实过的一方，并注明来源。
