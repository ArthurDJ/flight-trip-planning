# 机票决策 skill（中文版）

## 这个 skill 解决什么

搜索引擎回答"哪班最便宜"。这个 skill 回答 **"我们到底该订哪一班"**，答案取决于搜索引擎不管的那些事：

- **计划可能变**：签证或移民审批未定、工作学业日期未定、家庭安排。灵活性是有价格的，这个 skill 把它算成钱。
- **退款必须退现金**，不能是航司 credit（例如旅客要搬到别的国家，或很少再坐这家航司）。
- **跨境行程**：入境证件、在哪里过海关、转机时要不要重新托运行李。
- **替别人订票**（伴侣、父母、同事）：旅客需要一眼能看懂的结论，订票人需要能核对的依据。

它把这些变成硬性筛选条件和"多花多少钱换什么"的取舍，在航司官网核实候选，然后交付决策。**订票和付款由本人完成，agent 从不代劳。**

## 这个 skill 不做什么（交给现有工具）

| 需求 | 用什么 |
|---|---|
| 实时搜索、最便宜日期、附近机场 | Google Flights（日期网格、价格曲线）、Skyscanner、Kayak |
| 价格追踪、降价提醒 | Google Flights / Google AI Mode 的价格追踪、Kayak 提醒 |
| 该买还是该等的预测、锁价 | Hopper、Kayak 价格预测（不保证准确） |
| 里程兑换 | 航司官网、Google AI Mode 里程查询、专门的兑换工具 |
| **订票之后**选择退款、credit 还是保险理赔 | 订后退款决策类 skill |

这些工具的结果只用来**发现航班**，不作为最终价格。

## 模式

选最轻的一档，出现触发条件再升级。

| 模式 | 适用 | 提问数 | 输出 |
|---|---|---|---|
| **快速**（简单行程默认） | 境内、日期固定、无特殊约束 | 3–5 | 前 3 名对比卡 + 推荐 |
| **标准** | 任一：计划不确定、跨境、替别人订、超过 2 位旅客 | 6–10 | 对比表、取舍说明、旅客精简版 |
| **详细** | 影响大、日期 × 机场组合多、或有第二个 agent 审核 | 完整问询 | 带版本号的需求文档、完整结果文件、审核、出票记录 |

升级触发：旅客可能取消；行程跨境；转机依赖每天只有一班的航班；签证或移民身份待定；用户要求审核另一个 agent 的结果。

## 流程

1. **问询**：只问会改变决策的问题，其余用默认值并说明。见 `references/templates.md` 第 1 节。
2. **选偏好档位**（或由用户自定），档位规定"多付多少钱换什么值得"。见 `references/decision-framework.md` 第 2 节。
3. **设硬性筛选**：日期和时段（写明时区）、最长时长和转机次数、退改类别、行李、同一张票、证件。
4. **发现候选**：用用户的搜索工具，覆盖窗口内每一天、每个时段；从最稀缺的航段倒推（`references/verification.md` 第 2 节）。
5. **官网核实候选**：价格、票种、退改条款原文、查询时间。见 `references/verification.md`。
6. **折算真实总价**，并**给灵活性定价**（可退 vs credit vs 基础票）。见 `references/decision-framework.md`。
7. **评估可行性**：每个转机步骤、跨境规则、证件、时差、稀缺航段风险；套用对应的地区模块（`references/regions.md`）。
8. **决策并解释**：前 3 名，每条用金额写取舍（"多付 $27 换白天到达"），并说明更便宜或更近的选项为什么落选。
9. **交接**：旅客精简版、给其他 agent 的独立交接消息、出票清单。用户订完后做**出票后核对**。

## 核心规则

1. **先结论**：每份交付物开头先给推荐。
2. **绝不订票、付款、占座、登录或输入账号密码**；遇到登录或验证页面就跳过，留给本人处理。
3. **绝不占用用户正在用的浏览器标签页**；新开标签页，用完关掉。
4. **第三方结果只是线索**；最终价格、票种、退改条款以航司官网同一行程为准。
5. **口径不同不比较**：单程与往返、可退与不可退、含与不含行李的价格，不加"口径"列就不放在同一列。
6. **每个推断标置信度**（高 / 中 / 低）和依据；查不到写"未核实"，不推测。
7. **不悄悄放宽硬性条件**：无解就报告无解和原因，由用户决定。
8. **规则会变**：行李费、退改政策、入境规则、时区在执行时核实，并记录查询时间。
9. **始终标两地时间**：跨时区的起降写成"当地时间（另一地时间）"。

## 输出

- **对比卡**（所有模式）：前 3 名、真实总价、退改类别、两地时间、转机时长和风险、每条一句取舍。
- **旅客精简版**（标准及以上）：大白话，只放前 3 名，3–5 条注意事项（怎么取消、行李、证件）。
- **交接消息**（涉及其他 agent 时）：内容自包含，不引用对方打不开的文件。
- **完整结果文件和审核**（详细模式）。
- **出票记录**：出票后核对完成后写入。

模板见 `references/templates.md`。
